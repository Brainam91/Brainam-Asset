₹ How chips are calculated
Training vs Production usage · multipliers explained · worked examples

Cost in chips = Mode × Tier × Tokens

Mode multipliers

Production 1×
Live conversations with real customers. Charged at base rate — this is what the agent is for.
Training 2×
When you’re teaching, mock-testing, or refining the agent inside the Training Room. Double rate because each turn also runs the evaluation / Divya quality loops.

Feature tier multipliers

Basic 1×
  • Text chat with basic models (Haiku, GPT-4o-mini, Gemini Flash)
  • PDF / DOCX / TXT reading
  • Short-term memory
  • WhatsApp text, manual chat, plain webhooks
Pro 4×
  • Pro models — Claude Sonnet, GPT-4o, Gemini Pro
  • RAG / knowledge retrieval · long context (>32K)
  • Live tool calling (Apify, Firecrawl, Serper, etc.)
  • Database connections · web search
Multi Modal 6×
  • Image reading & vision · PDF with charts / diagrams
  • Image generation (DALL·E, Imagen, Flux)
  • OCR — receipts, invoices, screenshots
  • Visual Q&A · brand / logo detection
Ultra Pro 15×
  • Audio transcription (Whisper) · voice generation / TTS
  • Voice cloning · real-time voice agents
  • Video analysis · video generation (Veo, Runway, Sora)
  • Live call handling
