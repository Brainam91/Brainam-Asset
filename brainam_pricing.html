How chips work No upload size caps

1 chip ≈ 1 token.
You pay only for what the agent actually uses on each turn.

Standard usage burns the fewest chips. Premium features burn more — but never put a hard cap on what you can upload, ask, or analyse.

Standard usage low chip burn

💬

Quick replies with fast models (Haiku, GPT-4o-mini, Gemini Flash).

📄

Documents

Read PDF / DOC / TXT — no page limit, no file-size cap.

🧠

Conversation context carried across turns automatically.

📱

🔧

CRM lookups, Slack actions, web search — the agent uses tools when it needs to.

Why do premium features cost more chips?

Premium models think harder, retrieve more context, and process larger inputs — images, audio, long documents. Each turn uses more tokens, and chips track tokens 1:1.

The trade-off: we don't cap upload size or input length. A 100-page PDF, a 5 MB image, a 10-minute audio clip — all work on a single chip-pay turn. You only burn what the agent actually processes.
